# 第1章 绪论

> 稿件状态：正文初稿（2026-08-16）。

## 1.1 研究背景

### 1.1.1 传统村落保护中的木构建筑维护需求

传统村落并非单纯的物质空间遗产，而是由建筑本体、生活方式、地方材料和营造技艺共同构成的人居系统。对于以木构为主要承重或围护材料的民居而言，梁、柱、枋、檩、楼板、门窗等构件的状态既影响建筑安全，也影响村落风貌与文化表达的完整性。刘韫（2014）对嘉绒藏族民居的研究表明，甲居藏寨、中路藏寨等民族村落在旅游发展与现代化进程中面临传统民居保护与现实生活改善之间的矛盾；陈媛和李军环（2012）以丹巴中路乡藏族民居聚落为对象讨论其生态智慧与更新设计；胡冬雯和张菁（2025）进一步从“家屋”视角讨论嘉绒藏族民居的空间组织与有机更新。这些研究共同提示：嘉绒藏族民居保护不能只关注单体建筑立面，还需要把构件状态、使用方式和聚落尺度管理联系起来。

在丹巴嘉绒藏族民居中，本文将石砌墙体与木构件共同构成的建筑系统作为研究对象界定：石墙主要提供围护和稳定性，木构件承担楼面、屋面、联系和门窗等功能。这一界定服务于后续构件属性记录与空间分析，并不作为所有嘉绒民居构造类型的统计结论。木材在干湿交替、紫外线照射、生物侵蚀和长期荷载作用下会出现裂缝、腐朽、虫害、霉变等表观损伤。袁霄等（2021）基于古建筑木结构现场勘察信息指出，外部开裂、竖向变形、隐蔽处腐朽、内部腐朽和虫害等是木结构古建筑中的多发表观残损类型。对于大量分布在山地村落中的民居而言，这类损伤往往由局部开始，逐步影响构件耐久性和维修成本；若长期缺乏记录，则容易从可保养状态演变为需要大修甚至抢救的状态。

城乡规划工作需要对这类变化进行空间化、周期化和可比较的管理。与文物建筑的单体精细测绘不同，传统村落中的民居数量多、产权关系复杂、日常巡查人手有限，规划者更需要一种能在现场快速记录“哪栋建筑、哪个构件、出现什么表观损伤、大致程度如何”的辅助工具。由此，木构损伤识别不只是计算机视觉问题，也是传统村落保护监测和修缮资金配置中的基础信息采集问题。

### 1.1.2 人工巡查记录的痛点

现阶段传统村落巡查常依赖人工目视、拍照记录和表格填报。这种方式灵活，但也带来四类问题。

第一，记录粒度不稳定。巡查人员可能记录“某柱开裂”，但不同人员对裂缝长度、宽度和走向的描述不一致，后续难以横向比较。第二，影像与台账脱节。照片常按日期或人员归档，缺少与建筑编号、构件编号、空间位置的稳定关联。第三，复杂背景降低判读效率。木纹、木节、彩绘、雕刻、阴影、烟熏积炭、遮挡和拍摄距离变化，都可能使同类损伤呈现不同视觉形态，也可能使非损伤纹理被误认为损伤。第四，检测结果难以进入规划决策。即使识别出损伤类别和位置，若没有可测量的程度描述、标准依据和空间聚合方式，仍难转化为构件保养、建筑修缮或片区资金优先级安排。

上述问题说明，传统村落木构维护需要的不只是“识别准确率更高的模型”，而是从现场影像到规划决策之间的一条可追溯链路：检测对象是什么、在哪个构件上、图像中可测量到什么、换算为何种物理量、依据什么规则提示干预层级、最终如何落到建筑和聚落空间。

## 1.2 问题的提出

本文关注的核心问题是：**在复杂背景下，如何将传统木构建筑表观损伤从影像识别推进到可测量、可解释、可进入规划巡查流程的量化评估？**

围绕这一问题，当前研究与实践之间存在四个断层。

### 1.2.1 复杂背景与损伤特征混杂

木构损伤检测的对象常出现在非受控现场照片中。自然木纹与裂缝走向相似，木节与局部腐朽或表面缺陷形态相近，彩绘和雕刻增加纹理复杂度，阴影与光照变化改变颜色和对比度，遮挡与视角变化造成信息缺失。对于巡查照片而言，背景并不是可以简单裁掉的噪声，而是与损伤表现共同出现在同一画面中的干扰因素。若模型只学习全局外观，容易把背景纹理当作判别依据；若仅在干净样本上评估，也难以说明其在村落现场是否可用。

因此，本文将“复杂背景”作为需要显式定义和分层评价的条件，而不是只在引言中作定性描述。研究将背景干扰归纳为木纹、彩绘/雕刻、烟熏积炭、阴影/强光、遮挡、拍摄距离与尺度变化等因素，并在数据审计与后续实验中考察其对检测表现的影响。

### 1.2.2 表观类别与工程含义之间缺少分层

影像能够直接提供的是表观特征：颜色、纹理、形态、位置和范围。工程维护关心的则是损伤类型、几何量、发展趋势和是否需要干预。二者相关，但不能直接等同。例如，图像中的“深度腐朽”标签来自可见表观特征，并不等价于木材内部残余承载力；裂缝在图像中可见，也不必然代表结构已处于危险状态。若把检测输出直接写成工程结论，会造成越界解释。

为此，本文将检测结果与工程判断分层：检测层回答“是什么、在哪里”，测量层回答“图像中可观测到多大、多长、多密”，规则层依据标准或文献阈值给出干预提示，专业勘查层再决定最终处置。检测系统不替代结构安全鉴定。

### 1.2.3 长尾、小目标与数据不平衡

本文构建的 `wood_damage_v1` 数据集包含 2,443 张图像、5,774 个标注框和 7 个类别。其中 `wood_knot` 有 2,388 框，占全部标注框的 41.4%；而 `deep_decay` 和 `surface_defect` 分别只有 100 框和 71 框。头部类约为尾部类的数十倍，呈明显长尾分布。同时，归一化面积小于 1% 的标注框占 25.7%，小于 0.1% 的占 4.5%，说明细小裂缝、虫眼和局部病斑等小目标同样突出。

这种数据特征直接影响模型设计：只报告总体 mAP 会掩盖尾部类表现，无法说明系统在腐朽、表面缺陷等规划中更关心的类别上是否可用；只优化总体精度也可能牺牲小目标召回。因此，本文必须报告逐类指标，并按类别和目标尺寸进行分层分析。

### 1.2.4 检测输出与空间规划应用脱节

现有图像识别研究常止步于类别和边界框，而城乡规划需要可累积、可定位、可比较的事件记录。若检测结果不能转换为带建筑编号、构件类型、损伤量、时间和发展状态的台账，就无法与建筑价值、使用状态、产权、道路可达性、灾害暴露等信息叠加，也难以形成巡查路线和资金投放建议。反之，若仅为了空间统计而压缩损伤信息，又会丢失专业判断所需的细节。

因此，本文将 GIS 与移动巡查作为并列工作流：检测输出首先形成标准化损伤事件表，再与照片点、建筑面、构件属性和规划要素关联，最终支持损伤分布、风险热点和修缮优先级分析。

## 1.3 研究目标与研究问题

### 1.3.1 总体目标

本文面向传统木构建筑日常巡查，构建“复杂背景表观损伤检测—特征解耦—可测量量化—移动端采集—GIS 规划应用”的研究框架。研究不追求脱离部署条件的单一精度指标，而是强调检测、测量、标准映射和空间决策之间的闭环。

具体目标包括四点。

1. 建立适用于复杂背景木构表观损伤的冻结数据集与类别体系，量化其长尾、小目标和背景负样本特征。
2. 以 YOLO 系列轻量化检测为主线，建立可在 Android 端实时运行的表观损伤检测流程，并重点评估复杂背景、尾部类和小目标表现。
3. 将检测输出拆解为类别、几何、可测表现和背景干扰四类因子，在不引入人工 0—3 严重度标签的前提下，发展基于可观测几何与图像测量的类内量化方法，并研究其向物理尺度和标准干预层级映射的可行性。
4. 将损伤事件表接入 GIS，探索建筑/构件尺度的修缮优先级和片区巡查应用，使图像识别结果服务于城乡规划决策。

### 1.3.2 研究问题

本文将总体目标分解为四个研究问题。

**RQ1 复杂背景检测问题**：在传统木构建筑现场照片中，轻量化 YOLO 模型能否稳定识别裂缝、腐朽、虫害、霉变、表面缺陷和木节？其错误集中在哪些类别、背景和目标尺寸上？

**RQ2 特征解耦问题**：类别、几何、可测表现与背景干扰四类因子应如何定义、记录和验证？显式区分这些因子能否提高结果可解释性，并在可控实验中改善检测表现？

**RQ3 量化评估问题**：在不使用人工严重度标签的条件下，能否从检测框和 ROI 中提取裂缝长度/宽度、病斑面积占比、孔洞密度等可复现测量，并通过绝对深度估计将其换算为带不确定度的物理尺度？这些测量能否与 GB/T 50165—2020 等标准的干预规则建立可追溯联系？

**RQ4 移动端与规划应用问题**：检测模型能否导出至 Android NCNN 并维持可接受的实时性？标准化损伤事件能否与建筑、构件和空间要素关联，形成支持巡查和修缮优先级的 GIS 分析流程？

以上问题之间存在递进关系：RQ1 解决基础识别，RQ2 提高可解释性，RQ3 把检测结果转为工程可读量，RQ4 面向规划落地。第 4—6 章将分别给出对应实验与应用结果；本章不提前给出结论。

## 1.4 研究对象与边界

本文的研究对象是**传统木构建筑可见表观损伤的图像识别、量化与规划应用**。数据集类别包括裂缝、深度腐朽、虫害、霉变、表面腐朽、表面缺陷和木节。其中木节作为常见自然纹理和易混淆类别保留，用于检验模型区分损伤与木材天然特征的能力；在后续损伤指数中，木节是否计入损伤需依据类别语义和标准规则单独处理。

研究边界如下。

1. **表观检测而非内部无损检测**。本文主要利用可见光图像，识别和测量表面可见表现；木材内部腐朽、残余承载力和发展趋势需借助专业检测与结构鉴定。
2. **筛查辅助而非安全鉴定**。检测与量化结果用于巡查优先级、记录比对和现场复核，不直接输出结构安全结论。
3. **移动端实时检测与离线深度解算分离**。Android 端以 YOLO/NCNN 实时检测为目标，绝对深度估计和物理尺寸换算在离线环节完成，避免把全部复杂计算压入端侧实时链路。
4. **规划应用以事件和图层为核心**。GIS 输出是损伤分布和修缮优先级支持工具，不替代文物保护单位或住建部门的规定程序。

## 1.5 研究内容与技术路线

本文技术路线如下。

```text
现场照片
  → EXIF 方向矫正 / 必要畸变校正
  → 轻量化 YOLO 表观损伤检测（类别、位置、置信度）
  → 特征解耦：
       背景解耦：区分损伤前景与木纹、彩绘、阴影等干扰
       表征解耦：分别记录类别、几何、可测表现
       决策解耦：区分检测事实、测量结果与工程风险判断
  → 类内测量：
       裂缝：长度、宽度、方向
       腐朽/霉变/表面缺陷：面积占比、颜色与纹理变化
       虫害：孔洞数量与密度
  → 离线绝对深度估计与物理尺度换算
  → 标准规则映射与干预层级提示
  → 损伤事件表
  → GIS 空间分析与修缮优先级应用
```

图1-1将数据基础、表观检测、提示分割量化和规划应用组织为一条受证据门禁约束的研究链路。

![图1-1 复杂背景下木构表观损伤检测、量化与规划应用研究框架](../../../../outputs/thesis/chapter1/fig1-1_research_framework.svg)

相应研究内容包括五部分。

第一，构建并审计 `wood_damage_v1` 数据集。完成来源合并、重复与非法标签检查、固定划分、类别分布和小目标分析，为后续实验提供不可变数据基础。

第二，开展轻量化 YOLO 检测实验。以冻结划分为基础，训练集用于拟合，验证集用于模型选择，测试集仅在最终设计固定后使用一次。评价同时关注总体指标、逐类指标、尾部类和小目标表现。

第三，研究特征解耦与背景分层。背景解耦作为唯一可能进入网络的候选改动，需通过消融和 NCNN 导出验证；类别、几何、可测表现与决策边界的解耦主要在检测后处理与记录结构中实现。

第四，建立测量优先的量化方法。不同于人工给定 0—3 级标签，本文先提取可观测几何和视觉测量，再在标准或文献依据充分时映射为干预提示，并报告测量误差与不确定度。

第五，形成移动巡查与 GIS 应用方案。将检测台账与照片点、建筑/构件属性连接，输出损伤分布、热点和修缮优先级矩阵，讨论其在传统村落保护规划中的使用方式。

## 1.6 预期贡献

以下为本文拟形成的贡献，需待后续实验与应用案例验证。

1. **规划导向的闭环框架**：将木构表观损伤检测、可测量量化、标准映射和 GIS 修缮优先级连接为完整链路，而不是停留在模型精度比较。
2. **复杂背景下的特征解耦定义**：把“复杂背景”从笼统描述转化为背景干扰因子，把检测结果拆解为类别、几何、可测表现和背景四类可记录信息。
3. **测量优先的量化路线**：避免人工严重度标签，优先使用可观测几何与图像测量，并在有标准依据时进行干预层级映射。
4. **移动端与规划场景约束下的模型评价**：将逐类表现、小目标、复杂背景、NCNN 实时性和空间应用共同纳入评价体系。

## 1.7 论文组织结构

全文共分为七章。

第1章绪论，说明传统村落木构维护需求、人工巡查痛点、研究问题、目标和总体技术路线。

第2章相关研究综述，梳理木构损伤类型与勘查方法、图像识别与深度学习检测、损伤量化、移动端部署和规划应用研究，归纳本文切入点。

第3章数据集构建与损伤特征分析，介绍 `wood_damage_v1` 的来源合并、类别体系、划分冻结、审计结果、长尾与小目标特征及数据限制。

第4章面向复杂背景的木构损伤检测方法，报告轻量化 YOLO 基线、改进或训练策略、逐类和分层评价结果。

第5章损伤特征解耦与量化评估，阐述背景、表征与决策解耦方法，构建类内测量和物理尺度换算流程，并验证量化可靠性。

第6章移动端部署与规划巡查应用，讨论 Android NCNN 实时检测、损伤事件表、GIS 空间分析和修缮优先级应用。

第7章结论与展望，总结研究结论、应用价值、局限和后续方向。

本章小结：传统村落木构损伤巡查的关键矛盾在于，现场影像获取越来越便利，而影像中的表观信息尚未稳定转化为可测量、可追溯、可进入规划流程的证据。本文以复杂背景特征解耦与量化评估为中心，尝试在检测模型、测量规则、标准衔接和 GIS 应用之间形成闭环。
